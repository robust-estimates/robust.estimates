# Проверка API в Docker

Скрипт: scripts/check_api.py. Реальный запущенный Docker Compose с PostgreSQL и MinIO.

Результат: 11/11 этапов, 33/33 операций API, 177 запросов, 9.94 секунды. Расширенная проверка файла больше 10 МиБ включена. Все проверки пройдены.

Проверочные компании, заявки и документы сохранены как синтетические данные. Существующие записи не удалялись. Полный JSON-отчёт не содержит авторизационные заголовки, токены и пароль.
