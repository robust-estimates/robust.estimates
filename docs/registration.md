# Регистрация клиента

Метод: POST /api/v1/auth/register. Публичный, без токена и Idempotency-Key.

```json
{
  "login": "new-client@example.com",
  "displayName": "Иван Иванов",
  "password": "My-Credit-2026!"
}
```

Ответ 201: accessToken, tokenType, expiresIn и role=CLIENT. Сессия действует час; токен подходит для /me, компаний и заявок.

Email нормализуется; уникальность без учёта регистра обеспечивается SQL-индексом lower(login). Пароль — bcrypt. Поле role и другие неизвестные поля отклоняются. Самостоятельная регистрация сотрудника недоступна. В MVP email не подтверждается внешним сообщением.

Проверены unit-тесты регистрации/HTTP, конкурентная регистрация, хранение хеша, ошибки данных, лимиты, запрет повышения роли и ошибка подписания без записи пользователя. make check-go прошёл: gofmt, vet, Go -race и сборка трёх сервисов. OpenAPI 1.2.0 валиден.

Консольный прогон: 12/12 этапов, 34/34 операции, 185 запросов — успешно. Дополнительно прошёл кредитный E2E с зарегистрированным клиентом со сверкой ответов по OpenAPI. Интеграция выполнена на локальных процессах Go/Python, PGlite по PostgreSQL wire protocol и настоящем MinIO. Полный Docker-прогон новой регистрации не заявляется: загрузка образов в этой среде ограничена macOS Keychain.

Обновление Docker:

```sh
docker compose up --build -d --wait gateway
make e2e
```

Новая миграция 002 применяется gateway автоматически; файл 001 не менялся.
